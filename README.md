
# Install Openshift as Single Node on AWS

This repository contains a guide to installing an OpenShift cluster on a single AWS ec2 instance.
Whilst at least three master nodes and several worker nodes are required for production use,
a single-node cluster is perfectly suitable for testing, demonstrations or training.

## What you need

* Three server, two of them AWS ec2 isntances and at least one of them just temporary
* An own domain where you can add and change entries
* A pull secret which you may download from your RedHat user account

The detailed instruction can be found in
[openshift_single_node_aws_upi_installation_guide.md](openshift_single_node_aws_upi_installation_guide.md).
